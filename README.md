# Trabalho Semestral de Projeto Integrador.

### Objetivo
Desenvolver um sistema CRUD de marketplace utilizando JForm e SQL.

### Observação 
Feito para Java 27 ou posterior.
Para acessar o menu principal, execute o arquivo "backend.jar" na pasta "dist" para abrir o menu principal. Troque as varíaveis de usuário e senha no arquivo "conexao.java".
Não foi possível fazer um JAR que altere esses campos, então não é recomendado usa-lo.
